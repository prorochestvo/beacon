# Frozen Yahoo quotes are invisible to source health

**Status: dropped (2026-11-04).** Raised 2026-11-04 in the code review of plan 261104.0009.
Severity P3.

Resolution: the owner accepted the risk without a change. Delisting or a long halt of the
tracked tickers is unlikely, and the same staleness is already accepted for the crypto
sources since migration 202608.032.

Since negative JSON path indices skip nulls (plan 261104.0009, D1), a halted or delisted
ticker whose recent closes are all null except an old one keeps "succeeding" with a price up
to five days old. `SourceHealthAgent` measures silence since the last success, so it never
flags the source, and interval or daily digests show the old price as current. Delta
conditions stay quiet (delta 0).

Worth deciding: whether `doctor audit` (or the extractor) should flag a value whose bar
timestamp (`timestamp[-1]` of the same non-null element) is older than a threshold. Note that
negative indices are not positionally aligned across sibling arrays, so such a check has to
pair `close` and `timestamp` by position, not by two independent `[-1]` lookups.
