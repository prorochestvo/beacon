# Port the nightly doctor launcher to a single python3 script

**Status: open.** Raised 2026-11-02 in the review of plan 261101.0007. Severity P3.

`.agents/scripts/doctor-nightly.sh` is about 850 lines of bash with roughly 20 mutable globals
and four embedded python3 programs. python3 is already required; its standard library
(`zoneinfo`, `fcntl`, `subprocess`) would remove the dependency on the gnu-prefixed coreutils
of hive-warden-01 and let the fixture test run on mac-m1.

Worth deciding before the launcher's next feature: port it, or keep bash.
