# doctor audit --dsn ignores options.use_proxy per row

**Status: open.** Raised 2026-11-02 in the review of plan 261101.0007. Severity P2.

`doctor audit` proxies every source whenever `BEACON_PROXY_URL` resolves, while the collector
proxies only rows whose `options.use_proxy` is true. In `--dsn` mode the rows carry that
option, so the audit could match production egress exactly. Today the difference is inert: no
source opts in and the nightly launcher unsets `BEACON_PROXY_URL`. Commit 115a314 prints a
stderr warning in `--dsn` mode when a proxy is set.

Worth deciding: honour `options.use_proxy` per row in `--dsn` mode (and keep seed mode's
proxy-all behaviour), or keep the warning.
